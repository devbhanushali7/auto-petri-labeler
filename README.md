# auto-petri-labeler
This repository documents the development of a prototype automated Petri dish labeling system, covering the project from initial requirements and concept development through mechanical design, electronics, programming, and prototype testing. 
The project followed an iterative engineering approach, with different handling concepts evaluated before developing the final motion-based labeling mechanism. The prototype combines custom-designed and 3D-printed mechanical components with linear actuators, a servo motor, guide rails, an Arduino-compatible controller, and motor drivers.
